# agent

Agent für den Spielserver (Rust). Er meldet dem Backend den Zustand des Spielservers. Welten anlegen und führen kommt mit den nächsten Teilen von Schritt 7.

Was er darf und wie ein Spielserver aufgebaut ist, steht im [Konzept](../docs/konzept.md), Abschnitt 11.3. Wie er in der Testumgebung läuft, steht in der [Entwicklungsumgebung](../docs/entwicklungsumgebung.md).
