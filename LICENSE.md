# Lizenzen

Dieses Projekt verwendet mehrere Lizenzen, je nach Teil des Repositorys. Die vollständigen Lizenztexte liegen im Verzeichnis [`LICENSES/`](LICENSES/).

| Teil | Lizenz | Text |
|---|---|---|
| `backend/`, `agent/`, `frontend/`, `crates/`, `api/` | GNU Affero General Public License, Version 3 oder später | [`AGPL-3.0-or-later.txt`](LICENSES/AGPL-3.0-or-later.txt) |
| `mods/` (Code) | GNU Lesser General Public License, Version 3 oder später | [`LGPL-3.0-or-later.txt`](LICENSES/LGPL-3.0-or-later.txt) |
| Texturen, Klänge, Modelle und Texte, auch innerhalb von `mods/` | Creative Commons Namensnennung, Weitergabe unter gleichen Bedingungen 4.0 | [`CC-BY-SA-4.0.txt`](LICENSES/CC-BY-SA-4.0.txt) |
| `docs/` und übrige Dokumentation | Creative Commons Namensnennung, Weitergabe unter gleichen Bedingungen 4.0 | [`CC-BY-SA-4.0.txt`](LICENSES/CC-BY-SA-4.0.txt) |
| `scripts/`, `world-template/`, Konfiguration | GNU Lesser General Public License, Version 3 oder später | [`LGPL-3.0-or-later.txt`](LICENSES/LGPL-3.0-or-later.txt) |

Die LGPL 3 ergänzt die GNU General Public License, Version 3. Deren Text liegt deshalb ebenfalls bei: [`GPL-3.0-or-later.txt`](LICENSES/GPL-3.0-or-later.txt).

## Fremde Mods

Fremde Mods werden nicht in dieses Repository kopiert. Sie werden beim Einrichten in fester Version geladen und behalten ihre eigenen Lizenzen. Die Liste steht im Konzept, Abschnitt 14.1.

## Hinweis

Luanti ist ein eigenständiges Projekt mit eigenen Lizenzen. Dieses Projekt ist unabhängig und gehört nicht zum Luanti-Projekt.
